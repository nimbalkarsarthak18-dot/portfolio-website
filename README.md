## Overview

A high-production personal portfolio designed as a futuristic digital command center. Built with **React 18**, **Vite**, **Framer Motion**, and **Lucide Icons**, featuring:

- **Cinematic Atmosphere**: `#050505` obsidian base, deep crimson glowing accents (`#e50914`, `#ff1a2a`), subtle film grain, animated ember particles, and mouse-following ambient radial lighting.
- **Preloader**: Futuristic system initialization sequence (`0% → 100%`) with diagnostic checks.
- **Custom Adaptive Cursor**: Precision central dot with magnetic ring attraction on interactive buttons and radial glow on project cards.
- **Hero Section**: Oversized neo-noir typography, status indicators, and portrait visual framed with a glowing red circular moon halo and rim lighting.
- **01 / About**: Authentic narrative integrating mechanical engineering foundations with high-dimensional data science and edge computing.
- **02 / Skills Matrix**: Interactive ecosystem across 5 domains (*Programming & Data*, *Data Science & ML*, *IoT & Embedded*, *Web*, *Tools*).
- **03 / Data Lab**: Interactive 7-stage ML pipeline (`DATA → CLEAN → EXPLORE → ENGINEER → TRAIN → EVALUATE → DEPLOY`) with live diagnostic simulation.
- **04 / Selected Projects**: 9 curated engineering, data analytics, and robotics projects with architectural specifications and deep-dive modal viewer.
- **05 / Engineering Lab (Thermal Camera Rescue Robot)**: Control room HUD simulating live 8×12 MLX90640 thermal heat signatures, dual `[AUTONOMOUS]` and `[MANUAL]` modes, ultrasonic radar ranging, and motor drive telemetry.
- **06 / Journey**: Vertical timeline spanning 2025 to 2026 across mechanical foundations, analytics, machine learning, and robotics.
- **07 / GitHub Command Center**: Profile dashboard for [`nimbalkarsarthak18-dot`](https://github.com/nimbalkarsarthak18-dot) with simulated contribution heatmap and direct repository links.
- **08 / Contact Uplink**: Transmission terminal, one-click email copy with HUD toast notification, and social channels.
- **Fixed Navigation & HUD Section Tracker**: Fixed top bar with mobile cyber drawer + vertical `01–08` tracker with active section illumination.

## Quick Start & Running Locally

### 1. Prerequisites
- **Node.js**: v18.0.0 or later (Node.js LTS v24+ verified)
- **npm**: v9.0.0 or later

### 2. Installation
Navigate to the project root and install dependencies:
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 4. Build for Production
```bash
npm run build
```
The optimized static build will be output to the `dist/` directory, ready to deploy to Vercel, Netlify, or GitHub Pages.

## Customization Guide

### Personal Portrait
- Your portrait asset is located at `src/assets/portrait.jpg`.
- To swap in your own photo, simply replace `src/assets/portrait.jpg` with your desired image file.

### Contact Information & Social Placeholders
In `src/sections/Contact.jsx`:
- **GitHub**: Already set to `https://github.com/nimbalkarsarthak18-dot`
- **LinkedIn**: Replace `https://www.linkedin.com/in/sarthak-nimbalkar-placeholder` with your profile URL.
- **Email**: Replace `sarthak.nimbalkar@placeholder.com` with your real email address.

### Adding or Updating Projects
Modify `src/data/projectsData.js` to update titles, descriptions, metrics, or GitHub repository URLs.
